# Букетарня: сайт-магазин букетів з мила, цукерок і не тільки

Що всередині:

| Файл | Що це |
|---|---|
| `index.html` | сайт для клієнтів: каталог, конструктор букета, кошик, оформлення, відстеження |
| `admin.html` | адмін-панель: замовлення, товари, готові букети, налаштування |
| `shop.sql` | база даних Supabase: таблиці, правила доступу, функції, приклади товарів |
| `gallery.sql` | таблиця галереї робіт (додатково, якщо `shop.sql` вже виконано раніше) |

Без ключів Supabase `index.html` працює в **демо-режимі** (з прикладами, замовлення не зберігаються), тож його можна відкрити й подивитись одразу.

## Підключення за 6 кроків

1. **Supabase.** Зареєструйтесь на supabase.com → **New project** (назва, пароль бази, регіон поруч).
2. **База.** SQL Editor → New query → вставте весь `shop.sql` → **Run**. Мають створитись таблиці й приклади товарів.
3. **Ключі.** Project Settings → API Keys: скопіюйте **Project URL** і **Publishable key** (`sb_publishable_…`).
   Вставте їх на початку скрипту у **двох** файлах: `index.html` та `admin.html`:
   ```js
   const SUPABASE_URL = 'https://xxxx.supabase.co';
   const SUPABASE_KEY = 'sb_publishable_…';
   ```
   (ключ `secret` / `service_role` сюди вставляти **не можна**)
4. **Адміністратор.** Authentication → Users → **Add user** (ваша пошта й пароль, увімкніть «Auto Confirm User»).
   Потім у SQL Editor виконайте:
   ```sql
   insert into public.shop_admins (user_id)
   select id from auth.users where email = 'ВАША_ПОШТА@gmail.com';
   ```
5. **Хостинг.** Завантажте файли в репозиторій GitHub і ввімкніть Pages (Settings → Pages → Branch `main`).
   Сайт: `https://<логін>.github.io/<репозиторій>/`, адмінка: `…/admin.html`.
6. **Наповнення.** Зайдіть в адмінку: Налаштування (назва, телефон, ціни доставки), Товари (заміните приклади на свої, додайте фото), Готові букети.

## Галерея
- У адмінці розділ **🖼 Галерея**: «Додати фото» (можна вибрати одразу кілька), потім «Змінити» для назви, опису, категорій і прив'язки до готового букета.
- На сайті з'являється розділ «Галерея» з фото в окремих блоках. Клік відкриває вікно з описом, а для прив'язаного букета ще й зі складом, ціною та кнопками «У кошик» / «Змінити склад». Те саме вікно відкривається при кліку на готовий букет у каталозі.
- Якщо `shop.sql` вже виконано, додатково виконайте `gallery.sql`. Поки таблиці немає, розділ галереї на сайті просто прихований.

## Як це працює

- **Ціни рахує сервер.** Клієнт лише надсилає, що в кошику; функція `create_order` бере ціни з бази, перевіряє залишки й віднімає їх зі складу. Підмінити ціну в браузері неможливо.
- **Алкоголь (18+).** Для товару з позначкою «алкогольний» сайт просить підтвердити вік, а сервер не прийме замовлення без підтвердження. Алкоголь **не можна відправити поштою** (лише самовивіз і кур’єр).
- **Замовлення** бачить лише адміністратор. Клієнт відстежує своє за кодом і телефоном.
- **Скасування замовлення** повертає товари на склад.

## Важливо знати

- Продаж алкоголю в Україні потребує **ліцензії** і дотримання закону про торгівлю підакцизними товарами. Сайт лише вимагає підтвердження віку, а перевіряти документ потрібно при передачі замовлення. Це ваша відповідальність як продавця.
- Онлайн-оплати немає: «при отриманні» або переказ на картку за реквізитами, які ви надішлете клієнту.
- Сповіщень про нові замовлення поки немає: адмінка перевіряє нові кожні 40 секунд, поки відкрита (значок біля «Замовлення» й лічильник у заголовку вкладки).
